# DaisyUI Frontend Rewrite + Theme Switch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild Sushi admin/frontend templates with daisyUI + Tailwind v4, enable persisted `light/dark` theme switching, and keep current Rust/Lua behavior contracts unchanged.

**Architecture:** Migrate CSS toolchain to Node (`pnpm` + Tailwind v4 + daisyUI), keep single generated asset at `web/static/css/style.css`, and refactor templates (admin + official plugins) to daisyUI component semantics. Theme state is global at `<html data-theme>`, initialized early from `localStorage`, and unaffected by HTMX partial swaps.

**Tech Stack:** Tera templates, Alpine.js, HTMX, Tailwind CSS v4, daisyUI, pnpm, Rust test suite (`sushi-core`, `sushi-admin`).

---

## File Structure / Ownership

- `package.json` (+ lockfile): frontend build dependencies and scripts.
- `scripts/watch-css.sh`: watch-mode compiler entrypoint.

- `web/templates/base.html`: global shell, theme bootstrap, and theme toggle UI.
- `web/templates/admin/**`: admin pages + fragments migrated to daisyUI classes/components.
- `plugins/official/**/web/templates/**`: official plugin templates aligned to shared theme + component language.
- `web/static/admin/css/admin.css`: legacy stylesheet retired from runtime references.
- `crates/sushi-core/tests/template_service.rs`: template/static wiring verification.
- `crates/sushi-admin/tests/admin_web.rs`: admin page rendering/integration verification.

### Task 3: Global Theme Runtime (light/dark + persistence)

**Files:**
- Modify: `web/templates/base.html`
- Test: browser behavior + template tests

- [ ] **Step 1: Add early theme bootstrap script in `<head>`**

Implement logic:
```html
<script>
  (function () {
    try {
      var theme = localStorage.getItem("sushi-theme");
      if (theme !== "dark" && theme !== "light") theme = "light";
      document.documentElement.setAttribute("data-theme", theme);
    } catch (_) {
      document.documentElement.setAttribute("data-theme", "light");
    }
  })();
</script>
```

- [ ] **Step 2: Add theme toggle control in shared layout**

Use daisyUI control semantics and ensure:
- toggle reflects current theme
- click updates `data-theme`
- writes `localStorage["sushi-theme"]`
- updates `aria-pressed` (or equivalent accessible state)

- [ ] **Step 3: Remove runtime reference to legacy admin.css**

Delete from `base.html`:
```html
<link rel="stylesheet" href="{{ static_prefix }}/admin/css/admin.css">
```

- [ ] **Step 4: Verify no flash + persisted theme**

Manual checks:
1. switch to dark, refresh, stays dark
2. switch to light, refresh, stays light
3. HTMX partial refresh does not reset theme

- [ ] **Step 5: Commit**

